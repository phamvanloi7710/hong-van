# Changelog

All notable public release changes to Hong Van are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and public releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Planned

## [0.1.0] - 2026-08-12

### Added

- Initial public open-source baseline under the MIT License.
- Laravel 13 backend and Laravel Blade public rendering foundation.
- Angular 22 administration application with permission-aware features and localization foundations.
- Docker Compose environment using MySQL 8.4, Redis, Nginx, and PHP 8.5.
- CMS, product presentation, lead intake, media, SEO, audit, dashboard, and Page Builder foundations.
- Contributor guide, security policy, structured issue forms, and Pull Request template.
- GitLab CI quality, dependency, secret, and reference-source policy checks.
- GitHub Actions policy, backend, and Admin checks for public Pull Requests.

### Security

- Gitleaks history scanning and protected reference-source rules.
- Composer and npm dependency auditing.
- Private vulnerability reporting guidance and safe-harbor policy.

### Notes

- This is an early `0.x` release intended for evaluation, contribution, and controlled deployments.
- Checkout, online payment, and e-commerce order processing are intentionally out of scope.
