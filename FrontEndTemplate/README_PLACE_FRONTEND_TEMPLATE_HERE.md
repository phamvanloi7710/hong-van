# ĐẶT FRONTEND TEMPLATE TẠI ĐÂY

Chép source template website public vào đúng thư mục:

```text
FrontEndTemplate/
```

Quy tắc:

- Giữ nguyên cấu trúc source và file license.
- Không chép `node_modules/`, `dist/`, cache hoặc file build tạm.
- Không chỉnh sửa source trong thư mục này; đây là nguồn tham chiếu chỉ đọc.
- Website production vẫn được port sang `BackEnd/resources/views/` và render bằng Laravel Blade.
- Nếu source chưa có, Prompt P19 phải ghi `DEFERRED — SOURCE MISSING`, không tự tưởng tượng giao diện cuối.
