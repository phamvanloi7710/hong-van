# PROMPTS — HỒNG VÂN V2

- `PROMPT_INDEX.md`: danh sách 57 prompt, flag và checkpoint.
- `FULL_PROMPT_SEQUENCE.md`: toàn bộ prompt dạng Markdown.
- `FULL_PROMPT_SEQUENCE.txt`: toàn bộ prompt dạng text.
- `RUN_PROMPT_TEMPLATE.md`: mẫu giao từng prompt cho Codex.
- `00_...md` đến `56_...md`: từng prompt riêng để chạy tuần tự.

Template public dùng đường dẫn `FrontEndTemplate/`.

Không dán/chạy cả 57 prompt trong một lượt. Sau mỗi prompt phải kiểm tra `docs/CODEX_STATE.md`, `docs/TASK_LEDGER.md`, diff và test/build.
